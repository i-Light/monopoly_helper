# مساعد مونوبولي | Monopoly Helper (Flutter Edition)

تطبيق فلتر (Flutter) احترافي، معياري (Modular)، وسريع التجاوب لإدارة **الألعاب المصغرة وتحديات مونوبولي** (Monopoly Mini-Games Companion). تم تحويله بالكامل من مشروع CustomTkinter الأصلي إلى بيئة Flutter الحديثة ليعمل بسلاسة فائقة على **أجهزة الكمبيوتر (PC / Desktop / Web)** و**الهواتف الذكية (Android / iOS)**.

---

## 🖥️ تصميم الواجهة (Layout & Responsive Design)

تم تصميم واجهة التطبيق لتطابق منطق وترتيب وهيكل مشروع CustomTkinter الأصلي:

### 1. وضع سطح المكتب / الكمبيوتر (PC & Web Split Master-Detail Layout):

- **القائمة الجانبية (Sidebar)**:
  - ترويسة التطبيق (العنوان والوصف).
  - أزرار تصفية مستوى الصعوبة: `الكل`، `سهل (Easy)`، `متوسط (Medium)`، `صعب (Hard)`.
  - زر `🎲 اختيار لعبة عشوائية` البارز.
  - قائمة بالألعاب الـ 14 مع شارات الصعوبة والمؤقت الزمني لكل لعبة.
  - شريط سفلي يحتوي على إحصائيات الفوز وزر التبديل بين الوضع الليلي والنهاري.
- **مسرح التحدي التفاعلي (Main Stage Panel)**:
  - بطاقة علوية تحتوي على اسم اللعبة، شارة الصعوبة، وقواعد التحدي.
  - عداد تنازلي دائري متحرك (Animated Circular Timer) مع أزرار التحكم (بدء، إيقاف مؤقت، إعادة ضبط).
  - ساحة التحدي الرئيسية لتوليد الأسئلة، الكلمات، المسائل الحسابية، فئات الأتوبيس، لويات اللسان، وتأثير ستروب.
  - شريط الأزرار التفاعلية السفلية: `تحدي جديد`، `تم بنجاح`، `إخفاق`.

### 2. وضع الهواتف الذكية (Mobile Responsive Layout):

- تكيّف تلقائي ومرن للشاشات الرأسية.
- قائمة جانبية قابلة للسحب (Drawer) أو شريط تصفية سريع.
- واجهة تحدي كاملة الشاشة مع تحكم باللمس ومؤقت واضح.

## 🎮 باقة الألعاب الـ 14 المصغرة (14 Mini-Games Suite)

### 🟢 المستوى السهل (Easy):

1. **أتوبيس كومبليت السريع (Fast Stop the Bus)**: اذكر كلمات تبدأ بحرف محدد لـ 3 فئات قبل نفاد الوقت.
2. **تحدي القوافي (Rhyme Challenge)**: اذكر 3 كلمات على نفس الوزن والقافية مع الكلمة المحددة.
3. **الكلمة المعكوسة (Short Reverse Word)**: اقرأ أو تهجأ الكلمة بالعكس من اليسار لليمين.
4. **الحساب السريع (Speed Math)**: حل العمليات الحسابية الذهنية السريعة مع خيارات متعددة.

### 🟡 المستوى المتوسط (Medium):

5. **البحث عن الحرف المشترك (Common Letter Finder)**: اكتشف الحرف المشترك الوحيد بين 4 كلمات.
6. **أسئلة عامة ومنطقية (Common Questions & Logic)**: أسئلة ذكاء وثقافة عامة وتفكير منطقي مع خيارات.
7. **سلسلة الحرف الأخير (Last Letter Word Chain)**: تكوين سلسلة كلمات تبدأ بالحرف الأخير من الكلمة السابقة.
8. **الكلمة الشاذة (Odd One Out)**: استخراج الكلمة التي لا تنتمي للمجموعة وتوضيح السبب.
9. **الكلمات المحظورة / تابو (Word Ban)**: شرح الكلمة المستهدفة دون نطق أي من الكلمات المحظورة الخمس.

### 🔴 المستوى الصعب (Hard):

10. **الكلمة بشرطين (Double Constraint Word)**: ذكر كلمة تحقق قيدين محددين معاً.
11. **تحديات اللياقة البدنية (Fitness Challenges)**: تنفيذ تمارين ضغط، قرفصاء، وبلانك في وقت محدد.
12. **أتوبيس كومبليت المتقدم (Hard Stop the Bus)**: 5 فئات متقدمة وصعبة تحت ضغط الوقت.
13. **تأثير ستروب - الألوان (Stroop Effect)**: اختيار لون الحبر وتجاهل الكلمة المكتوبة.
14. **لويات اللسان (Tongue Twisters)**: تكرار الجمل الصعبة 3 مرات متتالية بسرعة ودون تلعثم.

## 📂 الهيكل المعماري البرمجي (Clean Architecture)

```text
monopoly_helper/
├── lib/
│   ├── main.dart                                # نقطة الانطلاق وإعداد الثيم والتوطين
│   ├── core/
│   │   ├── constants/                           # AppColors, AppStrings, AppTextStyles
│   │   ├── theme/                               # AppTheme (Material 3 Dark & Light), ThemeProvider
│   │   ├── utils/                               # TimerHelper, SoundHelper, ArabicTextHelper
│   │   └── widgets/                             # CustomCard, CustomButton, GameTimerWidget, DifficultyBadge
│   ├── data/
│   │   └── datasets/                            # بنك الأسئلة والبيانات العربية لجميع الألعاب الـ 14
│   └── features/
│       ├── home/
│       │   ├── state/                           # MiniGameState (متحكم الجلسة، المؤقت، والنتائج)
│       │   └── presentation/                    # الشاشة الرئيسية، القائمة الجانبية ومسرح التحدي
│       └── mini_games/
│           ├── core/                            # BaseMiniGame, MiniGameManager, MiniGameDifficulty
│           ├── easy/                            # كود ألعاب المستوى السهل (4)
│           ├── medium/                          # كود ألعاب المستوى المتوسط (5)
│           └── hard/                            # كود ألعاب المستوى الصعب (5)
├── test/                                        # اختبارات الوحدة (Unit Tests)
└── pubspec.yaml                                 # إعدادات الحزم الصافية الخالية من التعارضات
```

## 🚀 التشغيل والتطوير (How to Run)

```bash
# تثبيت الحزم
flutter pub get

# تشغيل على الكمبيوتر / الويب
flutter run -d chrome

# تشغيل على الموبايل
flutter run -d android

# تشغيل اختبارات الوحدة
flutter test
```
